### What I learned

This is the first project I used Tailwind for; it's the first time I used Tailwind, period. So while the site wasn't difficult to code, it took me more time than usual since I had to learn how to work with the framework. What I liked is, after getting used to Tailwind its logic is easy to understand so the process actually becomes much faster.

Another problem I faced was figuring out how to use Github's actions for deploying a page from custom folder. I also learned how to change VScode settings using JSON file, which isn't directly related to writing pages, maybe, but helped me organize nested divs. (I needed the setting that highlights active indentation)

### Continued development

I wanted to apply zoom effect to image on hover, however, it messes up rounded corners. I did not find a solution to this problem that would work for me, so I made zoom much smaller than I first wanted so change in the corners isn't that visible. I would want to find a solution for future projects since this kind of effect is often used. I decided to let go in this one since I already spent more time than I planned on it, with learning a new framework.
